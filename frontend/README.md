# Gerenciamento — React

Este frontend React mantém as telas e a identidade visual do `index.html` original. Os registros são carregados e salvos pela API Laravel em `/api`.

```powershell
npm install
npm run dev
```

O Vite encaminha `/api` para `http://127.0.0.1:8000`. Consulte o [README principal](../README.md) para iniciar o backend e executar os testes.
